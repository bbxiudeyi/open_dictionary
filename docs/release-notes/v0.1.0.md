# v0.1.0 · 首个版本 / First Release

## 中文

划词翻译 + 生词本桌面工具(Windows),**完全本地离线**——无 API、无账号、无遥测。

- 📸 **截图翻译**:按 `Ctrl+Alt+T` 框选屏幕区域,OCR + 翻译,译文浮窗显示在选区右侧,`ESC` 关闭
- ⌨️ **输入翻译**:按 `Ctrl+Alt+Q` 打开输入窗口(单击托盘图标也可截图翻译)
- 📖 **生词本**:翻译结果自动入库,支持搜索、删除、导出 CSV(Excel 直接打开不乱码)
- 🌐 **界面语言**:中文 / English,设置中随时切换
- 🔒 **本地模型**:NLLB-200-distilled-600M(CTranslate2 int8,纯 CPU,约 623MB)

**安装说明**:安装向导最后一步可选择立即下载翻译模型(默认走国内镜像 hf-mirror.com,自动校验);跳过也不影响安装,首次使用时在软件"设置"页下载即可(支持断点续传)。

## English

Snap-and-translate + vocabulary desktop tool for Windows. **Fully offline** — no API, no account, no telemetry.

- 📸 **Screenshot translate**: press `Ctrl+Alt+T`, drag a region — OCR + translation appear in a popup beside your selection; `ESC` to dismiss
- ⌨️ **Input translate**: press `Ctrl+Alt+Q` (single-click the tray icon for screenshot translate)
- 📖 **Vocabulary**: every translation is auto-saved; search, delete, and export to CSV (Excel-friendly)
- 🌐 **UI language**: English / 中文, switchable in Settings
- 🔒 **Local model**: NLLB-200-distilled-600M via CTranslate2 (int8, CPU-only, ~623 MB)

**Install note**: the setup wizard can download the translation model at the end (via hf-mirror.com by default, SHA-256 verified). Skipping is fine — download it later from the app's Settings page (resumable).
